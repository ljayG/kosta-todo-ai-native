# API 명세

| 항목 | 내용 |
| --- | --- |
| 문서 버전 | 0.1 (초안) |
| 관련 요구사항 | FR-01~FR-05, FR-13, FR-14, NFR-05, NFR-07 ([PRD.md](PRD.md)) |
| 구현 | FastAPI (`backend/`), 미구현 |

## 공통 규칙

- **기본 경로:** `/api`. 프론트엔드는 `VITE_API_BASE_URL` 환경 변수로 서버 주소를 받습니다.
- **형식:** 요청과 응답 본문은 JSON(`Content-Type: application/json`)입니다. 필드 이름은 DB와 같은 snake_case를 씁니다.
- **인증:** v1은 인증이 없습니다. 결정 필요 항목은 [spec-review.md](spec-review.md)의 D-01을 참고합니다.
- **CORS:** `ALLOWED_ORIGINS` 환경 변수에 적은 출처만 허용합니다.
- **필터와 통계:** 필터(FR-08), 통계(FR-09), 완료율(FR-10), 오늘의 작업(FR-07)은 서버가 아니라 화면에서 목록 전체로 계산합니다. 그래서 별도 API가 없습니다.

### Todo 객체

```json
{
  "id": "6f1c2a1e-1d7b-4c43-9f0e-2a6c1b9d8e11",
  "text": "주간 보고서 작성",
  "done": false,
  "priority": "high",
  "today": true,
  "created_at": "2026-11-25T09:00:00.000000+00:00",
  "updated_at": "2026-11-25T09:00:00.000000+00:00"
}
```

| 필드 | 타입 | 규칙 |
| --- | --- | --- |
| `id` | string (UUID) | 서버 생성, 읽기 전용 |
| `text` | string | 서버가 앞뒤 공백을 제거한 뒤 1~200자 |
| `done` | boolean | |
| `priority` | string | `high` \| `medium` \| `low` |
| `today` | boolean | |
| `created_at`, `updated_at` | string (ISO 8601) | 서버 기록, 읽기 전용 |

### 오류 응답

모든 오류는 FastAPI 기본 형식 `{"detail": ...}`를 씁니다.

| 상태 코드 | 상황 | 본문 예 |
| --- | --- | --- |
| 404 | 해당 id의 할 일이 없음 | `{"detail": "할 일을 찾을 수 없습니다."}` |
| 422 | 검증 실패 (빈 내용, 200자 초과, 잘못된 priority, UUID 형식 아님, 알 수 없는 필드) | FastAPI 기본 검증 오류 배열 |
| 500 | DB 오류 등 서버 내부 오류 | `{"detail": "서버 오류가 발생했습니다."}`. 내부 정보는 노출하지 않음 |

## 엔드포인트

### API-01 `GET /api/health`
서버 상태를 확인합니다(배포 확인용).
- **응답:** `200 {"status": "ok"}`

### API-02 `GET /api/todos` (FR-02, FR-13)
할 일 전체를 생성 순서(`created_at` 오름차순, 같으면 `id` 오름차순)로 돌려줍니다.
- **응답:** `200 Todo[]`. 없으면 `[]`.

### API-03 `POST /api/todos` (FR-01, FR-13)
할 일을 만듭니다.
- **요청:**
  ```json
  { "text": "주간 보고서 작성", "priority": "high", "today": true }
  ```
  - `text`: 필수.
  - `priority`: 선택, 기본값 `medium`.
  - `today`: 선택, 기본값 `false`.
  - `done`, `id`, 시각 필드를 보내면 422입니다.
- **응답:** `201 Todo`
- **오류:** `422`

### API-04 `PATCH /api/todos/{id}` (FR-03, FR-04, FR-13)
할 일의 일부 필드를 바꿉니다. 완료 처리(FR-03)와 수정(FR-04)이 모두 이 API를 씁니다.
- **요청:** `text`, `done`, `priority`, `today` 중 하나 이상.
  ```json
  { "done": true }
  ```
  - 빈 객체 `{}`, 알 수 없는 필드, `null` 값은 422입니다.
- **응답:** `200 Todo`. `updated_at`이 갱신됩니다.
- **오류:** `404`, `422`

### API-05 `DELETE /api/todos/{id}` (FR-05, FR-13)
할 일을 삭제합니다.
- **응답:** `204` (본문 없음)
- **오류:** `404`

## 프론트엔드 반영 규칙 (FR-14, NFR-07)

- **처음 불러오기:** 화면을 열면 API-02를 호출합니다. 응답 전에는 로딩 상태를 보여 주고, 실패하면 오류 문구와 "다시 시도" 버튼을 보여 줍니다.
- **변경 요청:** 등록, 수정, 삭제, 완료 처리는 **서버 응답을 받은 뒤** 화면에 반영합니다(비관적 업데이트). 요청 중에는 해당 버튼이 비활성화됩니다. 결정 필요 항목은 D-04입니다.
- **id:** 등록 후 서버가 돌려준 `id`를 그대로 씁니다. 프론트엔드에서 id를 만들지 않습니다.
- **변경 실패:** 화면 값을 바꾸지 않고 오류 문구를 보여 줍니다. 입력 중이던 내용은 유지합니다.
- **404 응답:** 다른 곳에서 이미 삭제된 경우이므로 화면에서도 그 항목을 제거합니다.
