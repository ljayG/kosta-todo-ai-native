## 결정 필요 항목

문서에는 제안안으로 적어 두었습니다. 사용자가 확정해야 합니다.

| ID | 내용 | 제안안 (문서에 반영된 값) | 영향 | 상태 |
| --- | --- | --- | --- | --- |
| D-01 | **인증 여부.** v1은 로그인이 없어서, 배포 주소를 아는 사람은 누구나 목록을 보고 바꿀 수 있습니다. | v1은 인증 없이 학습용 단일 목록으로 운영합니다. 공개 배포 위험을 감수하거나, 배포 주소를 공유하지 않습니다. | 높음. 인증을 넣으면 PRD 범위, `user_id` 컬럼, RLS 정책, API 인증 헤더, 로그인 화면이 추가됩니다. | 결정 필요 |
| D-02 | **"오늘 할 일"의 의미.** (FR-15 마감일 추가 후에도 `today`는 그대로 유지. 마감일로 대체할지는 여전히 결정 필요) 지금은 켜고 끄는 값이라 다음 날에도 남습니다. 이름과 동작이 어긋납니다. | v1은 현재 동작(불리언) 그대로 둡니다. 날짜 기반은 v2의 마감일 기능에서 다룹니다. | 중간. 날짜 기반으로 하면 `today`가 `due_date date`로 바뀌고 API와 화면이 달라집니다. | 결정 필요 |
| D-03 | **배포 구조.** 규칙상 백엔드는 `backend/`에 있지만, Vercel의 Python 함수는 기본적으로 `api/` 폴더를 씁니다. | Vercel 프로젝트를 둘로 나눕니다. 프론트엔드는 Root=`frontend`, API는 Root=`backend`와 `vercel.json`으로 구성합니다. | 중간. 하나로 합치면 폴더 구조와 CLAUDE.md가 바뀝니다. | 결정 필요 |
| D-04 | **화면 반영 시점.** 서버 응답 후 반영(비관적)하면 완료 체크가 약간 늦게 보일 수 있습니다. | 모든 변경을 서버 응답 후에 반영합니다. 단순하고 데이터 불일치가 없습니다. | 낮음. 낙관적 방식으로 바꾸면 롤백 처리가 추가됩니다. | 결정 필요 |
| D-05 | **삭제 확인.** 지금은 확인 없이 바로 삭제되며, 서버 저장 후에는 되돌릴 수 없습니다. | 현재 동작을 유지합니다(FR-05). | 낮음. 확인 대화상자나 되돌리기를 넣으면 FR-05와 AC-10이 바뀝니다. | 결정 필요 |

| D-06 | **마감일 세부 규칙 (FR-15).** 2026-11-25 마감일 구현 요청 시 사용자 답을 받지 못해 기본값으로 진행했습니다. | (1) `today`는 유지하고 `due_date`를 추가 (2) 날짜만, 화면 현지 날짜 기준 (3) PATCH `due_date: null`로 지우기 (4) 지난 마감은 미완료일 때만 강조, 정렬·필터 변경 없음 | 중간. 바꾸면 FR-15, API-03·04, AC-23~29가 바뀝니다. | 기본값으로 구현됨, 확인 필요 |

## 충돌 (문서끼리, 또는 문서와 코드)

| ID | 충돌 | 처리 |
| --- | --- | --- |
| C-01 | 프론트엔드는 `crypto.randomUUID()`로 id를 만들고, 명세는 서버가 id를 만듭니다. | **해결**(T-08): 서버가 준 id를 씁니다. |
| C-02 | DB와 API는 내용을 200자로 제한하지만, 화면 입력창에는 제한이 없습니다. | **해결**(T-10): `maxLength=200`을 추가했습니다(AC-03). |
| C-03 | 오늘의 작업에서 우선순위가 같은 항목의 순서가 코드에 정의되어 있지 않습니다. 지금은 JS 안정 정렬 덕분에 생성 순으로 나옵니다. | PRD FR-07에 "같으면 생성 순"으로 명시했습니다. 코드는 그대로 맞습니다. |
| C-04 | CLAUDE.md는 `docs/prd.md`를 가리키지만, 실제 파일은 `docs/PRD.md`입니다. | CLAUDE.md의 경로를 고쳤습니다. |
| C-05 | README.md에 "아직 기능 코드는 없습니다"라고 적혀 있지만 프론트엔드는 구현되어 있습니다. | T-13에서 갱신합니다. |
| C-07 | API 공통 규칙은 "PATCH에서 null 금지"인데, 마감일을 지우려면 `due_date: null`이 필요합니다. | **해결:** api-spec에 `due_date`만 예외로 명시했습니다. 다른 필드는 계속 null이면 422입니다. |
| C-06 | CLAUDE.md 구조에 `tests/`가 있지만 실제 폴더는 없습니다. | T-11에서 만듭니다. |
