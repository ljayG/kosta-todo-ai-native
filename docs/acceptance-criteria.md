# 수용 기준

[PRD.md](PRD.md)의 요구사항별 수용 기준입니다. 각 기준은 Given(전제) / When(행동) / Then(결과)으로 씁니다.

- **현재:** 표시가 "현재"인 기준은 지금 프론트엔드가 이미 구현하고 있습니다. 대부분은 브라우저 자동 테스트로 확인했습니다(2026-11-25, 19/19 통과). AC-06(텍스트 클릭으로 완료), AC-11의 색 띠, AC-12의 정렬 순서는 코드 검토로만 확인했습니다.
- **신규:** 표시가 "신규"인 기준은 백엔드를 연결한 뒤 검증합니다.
