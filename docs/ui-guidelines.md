# UI 가이드라인

My ToDo 프론트엔드(`frontend/`)의 디자인 규칙입니다. 현재 구현(`frontend/src/App.css`, `frontend/src/components/`)을 기준으로 정리했습니다. UI를 바꿀 때는 이 문서를 따르고, 규칙 자체를 바꿨다면 이 문서도 함께 고칩니다.

## 디자인 방향

- 개인용 데일리 플래너입니다. 종이(paper) 배경, 잉크(ink) 글자, 숲색(forest) 강조색을 씁니다.
- 대담한 요소는 **완료율 원형 링 하나**입니다. 나머지는 얇은 선(1px)으로 구분하고 그림자는 쓰지 않습니다.
- 새 요소를 추가할 때 강조 요소를 늘리지 않습니다. 그라데이션, 장식용 아이콘, 전부 대문자로 쓴 라벨, 카드마다 그림자를 넣는 방식은 쓰지 않습니다.

## 디자인 토큰

모든 색·반경·폰트는 `App.css`의 `:root` CSS 변수로만 씁니다. 색 값을 직접 쓰지 말고 필요하면 토큰을 추가하고, 다크 모드(`prefers-color-scheme: dark`) 블록에도 같은 이름으로 값을 정의합니다.

| 토큰 | 라이트 | 용도 |
| --- | --- | --- |
| `--paper` | `#f4f5f1` | 페이지 배경, 입력창 배경 |
| `--surface` | `#ffffff` | 패널·카드 배경 |
| `--sunken` | `#eceee8` | 탭 배경, 링 트랙 |
| `--line` / `--line-strong` | `#dadfd6` / `#c3c9bf` | 구분선, 테두리 |
| `--ink` / `--ink-soft` / `--ink-faint` | `#1c2620` / `#5f6b63` / `#8f998f` | 본문 / 보조 / 비활성·완료 텍스트 |
| `--forest` | `#2e6a4f` | 강조, 주요 버튼, 완료, 포커스 |
| `--p-high` / `--p-medium` / `--p-low` | `#b9412c` / `#8a6510` / `#3f6e8c` | 우선순위 높음 / 보통 / 낮음 (각각 `-soft` 배경색 있음) |

- 반경: `--radius-lg` 20px(요약 패널), `--radius` 12px(카드·폼), `--radius-sm` 8px(입력창·버튼). 배지·탭·세그먼트는 pill(999px). 위계에 맞게 고르고 하나로 통일하지 않습니다.
- 폰트: `--font` (Pretendard → Apple SD Gothic Neo → Malgun Gothic → system-ui). 웹폰트를 새로 불러오지 않습니다.
- 숫자(통계, 완료율, 개수)는 `font-variant-numeric: tabular-nums`를 씁니다.

## 컴포넌트 규칙

- **우선순위:** 색만으로 구분하지 않고 항상 텍스트(높음/보통/낮음)를 함께 보여 줍니다. 작업 카드는 왼쪽 색 띠와 `PriorityBadge`로 표시합니다.
- **마감일 (FR-15):** 카드의 메타 줄(우선순위 배지 옆)에 마감일 배지를 둡니다. 마감일이 없으면 배지를 그리지 않습니다.
  - 문구: 오늘 = "오늘 마감", 내일 = "내일 마감", 그 밖 = "마감 11월 28일 (금)". 연도가 올해와 다르면 "마감 2027년 1월 3일 (일)"로 연도를 붙입니다.
  - 마감일 배지는 채워진 우선순위 배지와 헷갈리지 않도록 **테두리형**(배경 없음)입니다. 기본은 `--line-strong` 테두리와 `--ink-soft` 글자, 오늘·내일 마감은 `--p-medium` 테두리와 글자입니다.
  - 미완료이고 마감일이 지났으면 "11월 20일 (금) 마감 지남"으로 쓰고, 유일하게 배경을 채워(`--p-high-soft` 배경, `--danger` 테두리·글자) 강조합니다.
  - 완료된 작업은 마감이 지났어도 강조하지 않고 중립색으로 날짜만 보여 줍니다.
  - 입력은 브라우저 기본 `<input type="date">`를 쓰고 보이는 라벨 "마감일"을 붙입니다. 비워 두면 마감일 없음입니다.
- **완료 상태:** 취소선과 `--ink-faint` 색, 카드 배경은 투명하게 합니다. 항목을 숨기지 않습니다.
- **버튼:** `.btn--primary`(숲색, 화면당 주요 행동 하나), `.btn--ghost`(보조), `.btn--danger`(삭제). 작은 버튼은 `.btn--sm`을 씁니다. 입력이 비어 있으면 실행 버튼은 `disabled`로 둡니다.
- **입력창:** 값이 있으면 오른쪽 안에 `ClearButton`(×)을 보여 줍니다.
- **Empty State:** `EmptyState` 컴포넌트를 쓰고, 무엇이 없는지와 다음에 할 행동을 함께 적습니다. 필터마다 문구가 다릅니다.
- **문구:** 존댓말, 짧은 평서문을 씁니다. 버튼은 동작을 그대로 적습니다(추가, 저장, 취소, 수정, 삭제).
- **클래스 이름:** BEM 비슷한 방식으로 씁니다. 블록 `.task`, 요소 `.task__body`, 변형 `.task--high`, 상태 `.is-done` / `.is-editing`.

## 서버 상태 표시 (FR-14, NFR-07)

- **처음 불러오기:** 작업 목록 자리에 "할 일을 불러오는 중입니다."를 보여 주고 목록 영역에 `aria-busy="true"`를 붙입니다. 스피너 애니메이션은 쓰지 않습니다.
- **불러오기 실패:** 목록 자리에 `EmptyState`로 실패 문구와 "다시 시도" 버튼을 보여 줍니다.
- **변경 실패 / 이미 삭제된 항목:** 입력 폼 아래에 `Notice` 띠를 보여 줍니다.
  - 무엇이 실패했는지와 다음 행동을 한 문장으로 적습니다. 사과하지 않습니다.
  - 오류는 `--danger` 계열, 안내는 `--forest` 계열 색을 씁니다.
  - `role="alert"`를 붙이고, 닫기 버튼이 있습니다.
- **요청 중:** 해당 작업의 체크박스와 버튼에 `aria-disabled="true"`를 붙이고 흐리게 표시하며, 눌러도 무시합니다.
  - `disabled`를 쓰지 않는 이유: 포커스된 요소가 비활성화되면 포커스가 사라져 키보드 사용자가 위치를 잃습니다.
  - 등록 중에는 "추가" 버튼이 "추가 중", 수정 저장 중에는 "저장" 버튼이 "저장 중"으로 바뀝니다.
  - 입력한 내용은 실패해도 지우지 않습니다.

## 레이아웃과 반응형

- `.layout`의 `grid-template-areas`로 배치합니다.
- **DOM 순서는 모바일 순서(입력 → 요약 → 목록)입니다.** 데스크톱에서는 grid-area로 위치만 바꿉니다. 새 영역을 추가할 때도 DOM 순서와 Tab 순서가 자연스럽게 유지되는지 확인합니다.

| 화면 너비 | 배치 |
| --- | --- |
| 880px 초과 | 2열: 왼쪽 요약(320px, sticky) / 오른쪽 입력·목록 |
| 561~880px | 1열: 입력 → 요약(링 왼쪽, 통계·오늘의 작업 오른쪽) → 목록 |
| 560px 이하 | 1열 세로 쌓기. 작업 카드 버튼은 아래 줄 오른쪽, 터치 영역 40px 이상 |

- 390px 너비에서 가로 스크롤이 생기면 안 됩니다.

## 접근성

- 포커스 표시는 전역 `:focus-visible { outline: 3px solid var(--focus) }`로 처리합니다. 개별 요소에서 outline을 제거하지 않습니다.
- 모든 입력에는 보이는 `label`이나 `.sr-only` 라벨, 또는 `aria-label`을 붙입니다. 목록의 버튼 라벨에는 작업 이름을 넣습니다(예: `"장보기" 삭제`).
- 원형 프로그레스는 `role="progressbar"`와 `aria-valuenow` / `aria-valuetext`를 씁니다.
- 필터 탭은 WAI-ARIA tabs 패턴을 따릅니다(roving tabindex, ←/→/Home/End).
- 포커스 이동 규칙:
  - 작업을 삭제하면 새 할 일 입력창으로 이동합니다.
  - 수정을 저장하거나 취소하면 해당 카드의 "수정" 버튼으로 돌아갑니다. 수정 입력창의 Enter/Escape 처리에서 `preventDefault()`를 지우면, 같은 Enter가 버튼 클릭으로 이어져 수정 모드가 다시 열립니다.
- 움직임은 `prefers-reduced-motion: reduce`에서 끕니다.
