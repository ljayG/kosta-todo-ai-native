
# Windows에서 GitHub 및 Claude Code 계정 정보 삭제 절차

> **목적:** 실제 GitHub·Claude 계정을 탈퇴하는 것이 아니라, Windows PC와 VS Code에 저장된 로그인 및 인증 정보를 삭제하는 과정입니다.

## 1. GitHub 계정 정보 삭제

### Step 1. GitHub CLI 로그아웃 (설치된 경우)

```powershell
gh auth logout
```

### Step 2. Windows 자격 증명 삭제

1. 제어판 실행
2. **자격 증명 관리자** 선택
3. **Windows 자격 증명** 선택
4. `git:https://github.com` 등 GitHub 관련 항목 확인
5. 해당 자격 증명 제거

### Step 3. Git 사용자 정보 삭제 (선택)

```powershell
git config --global --unset user.name
git config --global --unset user.email
```

- `user.name`, `user.email`은 Git 커밋 작성자 정보입니다.
- 로그인 인증 정보가 아니므로 계정 변경만 목적이라면 삭제할 필요가 없습니다.

### Step 4. VS Code GitHub 계정 로그아웃

1. VS Code 실행
2. 좌측 하단 **계정 아이콘** 선택
3. GitHub 계정 로그아웃

---

## 2. Claude Code CLI 계정 정보 삭제

### Step 1. Claude Code 실행

```powershell
claude
```

### Step 2. Claude 계정 로그아웃

```text
/logout
```

### Step 3. 인증 파일 삭제 (남아 있는 경우)

```powershell
Remove-Item "$env:USERPROFILE\.claude\.credentials.json" -Force -ErrorAction SilentlyContinue
```

- Claude Code의 로컬 인증 파일을 삭제합니다.
- `CLAUDE_CONFIG_DIR` 환경변수를 설정했다면 실제 저장 위치를 확인해야 합니다.

### Step 4. Windows 자격 증명 관리자 확인

1. 제어판 실행
2. **자격 증명 관리자 → Windows 자격 증명** 선택
3. Claude 또는 Anthropic 관련 항목 확인
4. 해당 항목이 있다면 삭제

### Step 5. API 인증 환경변수 확인 (사용한 경우)

```powershell
Get-ChildItem Env:ANTHROPIC*
```

- `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN` 등이 설정되어 있는지 확인합니다.
- 설정되어 있다면 해당 환경변수도 제거합니다.

---

## 3. VS Code에 로그인된 Claude 계정 삭제

### Step 1. VS Code에서 Claude Code 로그아웃

1. VS Code 실행
2. Claude Code 확장 화면 열기
3. Claude Code 채팅창에서 다음 명령어 실행

```text
/logout
```

4. 로그아웃 완료 여부 확인

> Claude Code 확장이 CLI와 인증 정보를 공유하는 환경이라면 CLI 로그아웃이 확장에도 적용될 수 있습니다.

### Step 2. VS Code 계정 메뉴 확인

1. VS Code 좌측 하단 **계정 아이콘** 선택
2. Claude 또는 Anthropic 관련 계정 항목 확인
3. 로그아웃 항목이 제공된다면 선택

> Claude Code 확장은 VS Code 계정 메뉴에 별도의 Claude 계정이 표시되지 않을 수 있습니다. 이 경우 Claude Code 확장 내부에서 로그아웃합니다.

### Step 3. Claude Code 인증 정보 삭제

VS Code를 종료한 후 PowerShell 실행

```powershell
Remove-Item "$env:USERPROFILE\.claude\.credentials.json" -Force -ErrorAction SilentlyContinue
```

- CLI와 VS Code 확장이 인증 파일을 공유하는 경우 함께 적용됩니다.
- 인증 정보가 다른 저장소에 있으면 해당 위치를 별도로 확인해야 합니다.

### Step 4. Claude Code 확장 제거 (선택)

1. VS Code 실행
2. 확장 메뉴 열기 (`Ctrl + Shift + X`)
3. `Claude Code` 검색
4. **Uninstall(제거)** 선택
5. VS Code 재시작

> 확장 제거는 계정 로그아웃과 다릅니다. 계정 변경만 목적이라면 확장을 제거할 필요가 없습니다.

### Step 5. 로그인 상태 확인

1. VS Code 재실행
2. Claude Code 확장 실행
3. 로그인 화면 또는 인증 요청 여부 확인
4. 기존 계정으로 자동 로그인되는 경우 남아 있는 인증 정보 확인

---

## 4. 계정 정보 삭제 확인

| 대상 | 확인 방법 |
|---|---|
| GitHub CLI | `gh auth status` |
| GitHub Git 인증 | 원격 저장소 접근 시 재인증 요청 여부 확인 |
| Claude Code CLI | `claude` 실행 후 로그인 상태 확인 |
| VS Code Claude Code | 확장 실행 후 로그인 상태 확인 |
| Windows 자격 증명 | GitHub 및 Claude 관련 항목 확인 |
| API 인증 환경변수 | `Get-ChildItem Env:ANTHROPIC*` |

### 주의 사항

1. GitHub의 `user.name`, `user.email`은 로그인 인증 정보가 아닙니다.
2. `.claude` 폴더 전체를 삭제하면 세션과 개발 설정까지 손실될 수 있습니다.
3. VS Code 확장 제거만으로 모든 인증 정보가 삭제되는 것은 아닙니다.
4. 브라우저에 저장된 GitHub·Claude 로그인 세션은 별도로 로그아웃해야 합니다.
5. SSH 키를 이용한 GitHub 인증은 Windows 자격 증명 삭제와 별도로 관리됩니다.

---

## 5. 핵심 정리

| 대상 | 계정 정보 삭제 순서 |
|---|---|
| **GitHub** | CLI 로그아웃 → Windows 자격 증명 삭제 → VS Code 로그아웃 |
| **Claude Code CLI** | `/logout` → 인증 파일 확인 및 삭제 → Windows 자격 증명 확인 |
| **VS Code Claude Code** | 확장 내부 `/logout` → 인증 파일 확인 → 확장 로그인 상태 확인 |
| **공통** | API 키·환경변수·브라우저 로그인 상태 확인 |

**권장 순서**

1. GitHub 로그아웃
2. Claude Code CLI 로그아웃
3. VS Code Claude Code 로그아웃 확인
4. Windows 자격 증명 및 인증 파일 정리
5. VS Code 재실행 후 계정 상태 확인
